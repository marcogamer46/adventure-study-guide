# Adventure Study Guide

A free, no-code course companion for the **Adventure Workbench** student project
(`src/student/`). Learn every concept — world model, terrain/level generation,
the controller, enemies vs. patrols, scoring, determinism, verification — and
then read the **real source code** of all six modules with line-by-line notes,
so you can explain, defend, and extend the project yourself.

Built as a single self-contained HTML file (no server, no build step). Hosted on
GitHub Pages.

## What's inside

- **11 concept sections** — from "what you built" through "defend your project"
- **Read the code** — all six `src/student/` modules, syntax-highlighted with
  line numbers and plain-language notes
- **Interactive terrain playground** — generate maps by topology + seed, watch
  determinism in action
- **Self-check quiz** with explanations
- **Glossary** of every key term
- Previous/next pager, sidebar scrollspy, theme toggle, back-to-top

## Run locally

Just open `index.html` in a browser. No internet needed beyond the Google Fonts
(which fall back to system fonts when offline).

## Host

Published via GitHub Actions-free static Pages — push `main`, Pages serves
`index.html` at the repo root.
